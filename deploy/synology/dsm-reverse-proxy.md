# DSM 局域网 HTTPS 反向代理

只在 loopback 隔离部署、自动测试和人工浏览器验收全部通过后执行。

## 新增规则

- 控制面板 → 登录门户 → 高级 → 反向代理服务器 → 新增。
- 描述：`MakerSeed 科创诊断记录`。
- 来源协议：HTTPS。
- 来源主机名：留空或使用工坊局域网专用名称。
- 来源端口：`18443`。
- 目的地协议：HTTP。
- 目的地主机名：`127.0.0.1`。
- 目的地端口：`18081`。
- 启用 HTTP/2；WebSocket 不需要。
- 选择 DSM 中已有、适用于访问名称的证书；不要关闭证书验证或要求老师绕过安全警告。

## 防火墙

- 新增允许规则：来源只允许工坊局域网网段，目标端口 `18443/TCP`。
- 在该端口后添加拒绝其他来源规则。
- 不添加路由器端口转发，不把此服务加入 QuickConnect，不改变 DDNS。

## 验收

- 局域网老师电脑通过 HTTPS 登录。
- 外部移动网络不能连接 `18443`。
- `127.0.0.1:18081` 不直接暴露到 LAN。
- Secure/HttpOnly/SameSite Cookie 均存在，HTTP 入口不可用。
