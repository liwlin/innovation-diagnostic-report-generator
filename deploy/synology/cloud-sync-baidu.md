# 百度云 Cloud Sync 项目备份配置

此步骤只创建新的“科创诊断报告”任务，不编辑、暂停、删除或复用任何公司资料 Cloud Sync 任务。

## 前提

- 正式报告共享文件夹：`科创诊断报告`。
- 数据库备份目录：`/volume1/docker/makerseed-diagnostic/backups`，只允许管理员访问。
- 使用专用、非个人 DSM 服务账号创建任务；账号只拥有上述项目路径的必要权限。
- 先准备两个不同地点的离线介质，用于保存 Cloud Sync 导出的解密密钥。

## 任务 A：报告文件

1. Cloud Sync → 任务列表 → 新增，仅选择现有百度云连接。
2. 本地路径只选择 `科创诊断报告`。
3. 远端路径使用项目专用子目录，不选择百度云根目录或公司资料目录。
4. 同步方向选择“仅上传本地更改”。
5. 勾选“源端删除时不删除目标端数据”。
6. 开启“数据加密”。
7. 不设置会遗漏 PDF/PNG 的扩展名过滤；设置合理带宽和非上课时段。

## 任务 B：数据库备份

1. 新建第二个项目任务，本地路径只选择项目 `backups` 目录。
2. 使用独立远端子目录。
3. 同样选择“仅上传本地更改”“源端删除时不删除目标端数据”“数据加密”。
4. 只包含 `.dump`、`.sha256`、`.json`；不包含 `secrets`、`.env`、数据库物理目录或部署日志。

## 密钥与验收

- 第一次开启加密后立即导出 Cloud Sync 密钥。
- 两份密钥离线保存；不得放在 NAS、GitHub、同一百度云账号或项目备份目录。
- 禁止在百度云中直接修改 `@SynologyCloudSync` 加密目录。
- 使用非敏感测试备份完成一次上传、下载和解密；比对 SHA-256 后再启用正式任务。
- 每月检查最后成功同步时间、失败记录和云端容量。

## 失败处理

- Cloud Sync 失败不停止局域网应用，也不删除本地成功备份。
- 先保留最后一份已验证本地备份，再处理网络/账号问题。
- 任何需要清理云端历史副本的操作都必须使用 Cloud Sync 支持流程，并先证明另一份较新备份可恢复。
