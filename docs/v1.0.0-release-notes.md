# 科创体验诊断报告生成器 v1.0.0 · GitHub Pages 静态版

这是 GitHub Pages 静态版的首个稳定 Release，适合科创体验课、创客活动和课程咨询后的学生诊断报告制作。

## 主要功能

- 批次与多学生记录管理
- 历史批次切换
- 五维能力评分与三种图表
- 课堂观察、技能点、推荐方向和建议班级
- 含/不含工坊内部记录的两种报告
- PNG 导出与浏览器打印/PDF
- 当前批次批量打印
- 可选的浏览器直连 AI 润色

## 使用方式

- 在线版：<https://liwlin.github.io/innovation-diagnostic-report-generator/>
- 离线版：下载本 Release 的 `innovation-diagnostic-report-generator-v1.0.0-static.zip`，解压后打开 `index.html`

## 数据与隐私提醒

- 业务数据保存在当前浏览器 `localStorage`，不会自动跨设备同步。
- 清除站点数据、浏览器缓存或重装系统可能导致记录丢失。
- AI API Key 仅保存在当前浏览器；AI 请求会直接发送到用户配置的第三方接口。
- 请勿把敏感学生信息提交给未经授权的第三方 AI 服务。
- 建议定期保存生成后的 PDF/PNG 文件。
