## 字体

- UI：`"PingFang SC", "Microsoft YaHei", system-ui, sans-serif`
- 主标题：28px / 700 / 1.25
- 页面标题：22px / 700 / 1.3
- 表头与按钮：14px / 600 / 1.4
- 正文与表格：14px / 400 / 1.5
- 辅助文本：12px / 400 / 1.5
- 所有输入、选择和按钮显式继承 UI 字体，不使用浏览器默认控制字体。

## 桌面布局

- 视口基准：1440×900；1366×768 仍能看到导航、过滤器和至少四条记录。
- 左侧导航：220px，白色，右边 1px 边框；Logo 置顶。
- 顶栏：64px，页面标题和版本在左，当前用户和退出在右。
- 主区：24px 边距；工具栏与过滤器紧凑排列。
- 记录使用开放表格，不改成卡片网格。
- 选中行使用浅蓝背景；悬停只改变背景，不移动布局。
- 表格操作使用蓝色文本按钮；永久删除使用危险色并只出现在管理员回收站。

## 响应式

- `< 980px`：左侧导航变成顶部水平导航；过滤器允许两行；表格区域水平滚动。
- `< 640px`：登录表单保留 16px 屏幕边距；仪表盘工具栏纵向排列；表格保持最小宽度，不压缩成难扫描卡片。
- 焦点轮廓必须清晰；支持 `prefers-reduced-motion`。

## 组件家族

- `AppShell`：Logo、导航、顶栏、版本、当前用户、退出。
- `LoginView`：账号、密码、错误提示、登录按钮、安全说明。
- `RecordToolbar`：新建、姓名搜索、组合过滤器。
- `RecordTable`：学生、日期、批次、年级、推荐班、最后修改、报告状态、操作。
- `RecycleTable`：恢复；管理员额外显示永久删除。
- `UserTable`：管理员创建、角色、启用状态、密码重置。
- `AuditTable`：按操作者、动作、目标和日期筛选。
- `ConfirmDialog`：危险操作二次确认与原因输入。
- `StatusMessage`：加载、空结果、保存失败、登录失效；不使用装饰性徽章。

## 图标

- 导航允许四个 18px、1.75px 描边、`currentColor` 的代码内联 SVG：记录、回收站、账号、审计。
- 下拉、分页和返回使用同一 16px 线性 SVG 家族。
- 不使用 Emoji、字体图标或第三方图标包。
