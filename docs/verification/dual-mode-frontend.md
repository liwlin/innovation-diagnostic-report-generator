## 本地 React 故障与修复

首次编辑器测试发现 `support.js` 尝试从 unpkg 加载 React，严格 CSP 阻止第三方脚本，页面为空。修复方式：

- 从 npm 官方包 `react@18.3.1`、`react-dom@18.3.1` 提取固定 UMD 文件。
- `react.production.min.js` SHA-256：`d949f1c3687aedadcedac85261865f29b17cd273997e7f6b2bfc53b2f9d4c4dd`。
- `react-dom.production.min.js` SHA-256：`35f4f974f4b2bcd44da73963347f8952e341f83909e4498227d4e26b98f66f0d`。
- 随仓库保存两个 MIT License。
- 编辑器先加载 `/vendor/react.production.min.js` 和 `/vendor/react-dom.production.min.js`。
- CSP 没有因此增加第三方脚本源。
- 修复后新标签页控制台为零 error/warn，编辑器完整加载。

## 证据边界

- 当前浏览器服务使用 SQLite 和 Windows 字体，不是 PostgreSQL/容器/NAS。
- DSM HTTPS、Secure Cookie、File Station、Cloud Sync 和 NAS 资源占用仍未验证。
- 账号/永久删除等高风险浏览器提交由自动化 API 测试替代，避免在浏览器自动执行账户与删除最终步骤。
